# Security Policy

## Supported versions

Only the live site at [kavisha.online](https://kavisha.online/), built from the `main` branch, is supported. Fixes land through `dev` and ship with the next release to `main`.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub instead:
[**Report a vulnerability**](https://github.com/MacroMaster101/kavisha_portfolio-V2/security/advisories/new)
(Security tab → Advisories → *Report a vulnerability*).

Useful details to include:

- what is affected (page, header, workflow, or dependency)
- steps to reproduce or a proof of concept
- the impact you expect

## What to expect

- Acknowledgement within **3 days**
- An initial assessment within **7 days**
- A fix or mitigation as soon as practical, with credit in the advisory if you would like it

## Scope

In scope: this repository's source, its GitHub Actions workflows, and the security headers served by the deployed site.

Out of scope: third-party services the site links to or embeds (GitHub, Spline, Vercel, Google Fonts) — please report those to their owners.
